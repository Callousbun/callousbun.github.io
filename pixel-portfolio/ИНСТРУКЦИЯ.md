# Инструкция

1. Распакуйте архив и дважды щёлкните по `index.html` — сайт откроется в браузере.
2. Тексты, контакты, ссылки, пути к картинкам и список работ — в файле `config.js` (открывайте Блокнотом).
3. Картинки: работы — `assets/gallery/`, аватарка, иконки, статус-GIF — `assets/ui/`, нижний арт — `assets/footer/`.
4. Новая работа: положите файл в `assets/gallery/`, скопируйте один блок `{ file: ..., format: ..., desc: {...} }` в `gallery` в `config.js`, поменяйте путь и описания.
5. Замена заглушек: сохраните свой файл с тем же именем и в ту же папку (или поменяйте путь в `config.js`).
6. GitHub: создайте репозиторий (New repository, Public) → Add file → Upload files → перетащите содержимое папки (не сам архив; `index.html` должен лежать в корне) → Commit. Затем Settings → Pages → Source: Deploy from a branch → Branch: main, папка /(root) → Save. Через 1–2 минуты сайт откроется по ссылке `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

## Замена кнопок, стрелок и ползунка своими PNG
Все пути лежат в `config.js`, раздел `images`. Просто сохраните свои файлы поверх заглушек с теми же именами (папка `assets/ui/`) или поменяйте пути.
- Кнопки языка, стрелки, иконки контактов: три файла — обычное (`normal`), наведение (`hover`), нажатие (`active`). Все три файла одной кнопки должны быть одного размера. У кнопки выбранного языка всегда показывается файл `active`.
- Ползунок: `slider-track.png` и `slider-fill.png` — маленькие плитки, которые повторяются по горизонтали (должны стыковаться без шва), `slider-thumb.png` — бегунок.
- Все эти картинки показываются в целом масштабе не меньше 2x (число меняется в `minUiScale` в `config.js`).
- Листать работы в просмотре: стрелки на экране, клавиши ← →, свайп на телефоне. Ползунок с клавиатуры: ↑ ↓.

## Просмотр: колёсико и кнопка закрытия
- Колёсико мыши в просмотре меняет масштаб (1x–10x) к точке под курсором. Ползунок приближает к центру видимой области. Страница под просмотром не прокручивается.
- Кнопка закрытия — три PNG: `assets/ui/close.png`, `close-hover.png`, `close-active.png` (пути в `config.js`, `images.close`).

## Заголовок
Текст на двух языках — `title` в `config.js`. Пустая строка `""` скрывает заголовок.

## Шрифты
В начале `style.css` есть блок «ШРИФТЫ». У каждого места свои переменные: `--ff-…` (шрифт) и `--fs-…` (размер):
`title` — заголовок, `welcome` — текст приветствия, `contact` — адреса и ники, `hint` — «(click to copy)», `toast` — «Copied!», `desc` — описания в галерее, `caption` — описание в просмотре, `zoom` — подпись «3x» у ползунка.
- Размер: поменяйте число, например `--fs-title: 32px;`. Для телефонов размеры переопределяются ниже, в `@media (max-width:480px)`.
- Шрифт: впишите название, например `--ff-title: "Courier New", monospace;` (последнее слово — запасной вариант).
- Свой шрифт: положите файл (лучше `.woff2`) в `assets/fonts/`, раскомментируйте блок `@font-face` в `style.css`, поставьте там имя файла и впишите `"MyFont"` в нужные `--ff-…`. Для пиксельных шрифтов размер лучше брать кратным тому, под который шрифт нарисован.

## Рамки (приветствие и контакты)
Файлы лежат в `assets/ui/frames/welcome/` и `assets/ui/frames/social/` (по 9 тайлов: top-left, top, top-right, left, center, right, bottom-left, bottom, bottom-right; суффикс `-1` — номер вариации). Настройки — `frames` в `config.js`.
- Все тайлы одного набора должны быть одного размера. Углы рисуются один раз, края и центр повторяются плиткой.
- Вариации: положите, например, `top-2.png` и `top-3.png` и допишите пути в список `top: [...]`. При каждой загрузке страницы для каждой клетки выбирается случайный файл.
- `scale` — масштаб тайлов (целое, не меньше 2). `borderWidth` — толщина рамки в пикселях тайла: на столько содержимое отступает от края. `padding` — дополнительный отступ.
- При наведении на контакт рамка светлеет, при нажатии темнеет (средствами CSS, без отдельных файлов).

### Уточнения по рамкам
- Размер рамки всегда кратен размеру тайла: ширина округляется вниз до целого числа тайлов (поэтому рамка может немного не доходить до правого края), высота округляется вверх. Тайлы не обрезаются и не накладываются друг на друга.
- Тайлы — квадраты любого размера (16, 20, 24 и т. д.), размер берётся из файлов автоматически. Все тайлы обоих наборов лучше делать одного размера.
- Вероятность вариаций задаётся в `config.js`: `variantWeights: [70, 20, 10]` — 1-я вариация в списке 70%, 2-я 20%, 3-я 10%. Если вариаций в списке больше, чем чисел, у лишних вес как у последнего числа.
- `borderWidth: null` — содержимое отступает на толщину целого тайла. Если сама рамка тоньше тайла, впишите число (в пикселях тайла).
